# 镜留 1.3.0 · Android

安装包：`jingliu-1.3.0.apk`，适用于 Android 8.0 及以上。

已安装 1.1.0 / 1.2.0 的手机可直接覆盖升级，记忆与收藏会保留。把 APK 传到手机，点击安装；如果系统询问，允许当前文件管理器安装此应用即可。

- 新增「行星近观」：八颗行星与月球的三维模式，可单指旋转、双指缩放，开启或暂停缓慢自转。地图离线内置，未找到合适完整地图的部分用模拟纹理补充并注明。
- 三维视图有土星环投影、地球云层与月面凹凸；设备不支持 WebGL 2 时显示静态预览。
- 收录 20,000 颗真实恒星，保留 88 个星座与旧记忆坐标。
- 春、夏、秋、冬四个星区，点击即可漫游；区域之间没有分隔线，星名、星座连线和网格默认关闭，放大后逐步显示暗星。
- 独立的观星区与集中的操作入口，减少遮挡；星星带有亮核、渐变光晕与细星芒。
- 统一的照片相框、纸感弹窗与表单，适配小屏和横屏。支持双指缩放和星体大小调节。
- 星图、封面、字体内置，离线可用。记忆、照片、收藏保存在本机。
- 「我的 → 带走我的回忆」会打开系统文件保存器；「导入回忆备份」可恢复之前导出的 JSON，兼容网站备份。

当前 APK 是本机离线版，未接入网站账号服务，不提供登录和云端同步。换机、卸载或清除应用数据前，请导出回忆备份。本机照片存储有容量限制，空间不足时会提示。

安装包使用项目专属密钥签名；后续保留同一签名即可覆盖升级。源码中的 `.android-signing/` 用于后续构建，请妥善保留，不要分享其中的密钥和密码。重新构建运行 `npm run build:apk`。
