# 镜留 1.1.0 · Android

安装包：`jingliu-1.1.0.apk`，适用于 Android 8.0 及以上。

把 APK 传到手机，点击安装；如果系统询问，允许当前文件管理器安装此应用即可。

- 收录 20,000 颗真实恒星，保留 88 个星座与旧记忆坐标。
- 春、夏、秋、冬四个星区，点击即可漫游；区域之间没有分隔线，星座连线和网格默认关闭。
- 星星带有亮核、渐变光晕与细星芒；支持双指缩放和大小调节。
- 星图、封面、字体内置，离线可用。记忆、照片、收藏保存在本机。
- 「我的 → 带走我的回忆」会打开系统文件保存器；「导入回忆备份」可恢复之前导出的 JSON，兼容网站备份。

当前 APK 是本机离线版，未接入网站账号服务，不提供登录和云端同步。换机、卸载或清除应用数据前，请导出回忆备份。本机照片存储有容量限制，空间不足时会提示。

安装包使用项目专属密钥签名；后续保留同一签名即可覆盖升级。源码中的 `.android-signing/` 用于后续构建，请妥善保留，不要分享其中的密钥和密码。重新构建运行 `npm run build:apk`。
