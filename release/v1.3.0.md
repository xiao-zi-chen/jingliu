镜留 1.3.0 新增「行星近观」。从星海上方进入三维模式，拖动八颗行星与月球，靠近土星环、地球云层和月面细节。

- 单指拖动旋转，双指或滚轮缩放，也可使用按钮、键盘与复位。缓慢自转可以手动开启或暂停。
- 土星采用球体、独立星环与投影；地球使用公开地表地图、云层及模拟大气边缘；月球用颜色与高程贴图表现细节。
- 地球、月球、木星、火星与土星使用 NASA 公开地图。缺少合适完整地图的部分自行补做：水星地貌、金星云顶、天王星与海王星云层，以及土星环。每个天体都注明地图和模拟来源。
- 大幅星球、说明与控制分开摆放，底部一排缩略图切换，适配小屏与横屏。原来的四季星区、20,000 颗恒星与记忆功能继续保留。
- 素材与代码随 APK 离线打包，静止或进入后台时停止绘制；三维资源按需载入并在退出时回收。不支持 WebGL 2 的设备提供静态预览，地图加载失败时使用有标注的模拟纹理。

**安装：** Android 8.0 及以上。下载 `jingliu-1.3.0.apk` 后直接安装，沿用 1.1.0 / 1.2.0 的应用标识与签名，可覆盖升级并保留本机记忆与收藏。

**显示说明：** 三维视图用于欣赏，天体未按同一比例展示，光照与转速为演示，不提供实时位置或当前云层。月球是天然卫星。当前 APK 仍是本机离线版，不提供账号登录或云同步。
验证完成：10 项接口与数据测试、50 项桌面/手机浏览器用例（含修正后的三维复测），以及 Android release 构建、Lint、签名、资源一致性与对齐检查。检查了 320px 小屏、横屏与不支持 WebGL 的静态预览。本次未连接 Android 真机，尚未实际安装验证。
